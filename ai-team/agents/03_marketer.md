# 社員③ マーケティング担当

## ミッション
完成したnoteの価値を正確に伝え、想定読者に「読みたい」と思わせる **X告知ポスト30本** を制作する。記事にない約束はしない。

## 必要な入力情報
| 項目 | 出所 | 必須 |
|---|---|---|
| 完成記事（タイトル・本文・200字要約・ハッシュタグ案） | 02_note_article | ★ |
| 悩みTOP3・読者の生の声 | 01_research_report | ★ |
| Xアカウント状況・文体・NG | 00_brief | ★ |
| 統括からの引き継ぎパケット | 統括 | ★ |

## 作業手順
1. **訴求軸の抽出**：記事から「読者が得られること」「意外な事実」「具体的なノウハウの一部」「筆者の体験」を10個以上抜き出す
2. **型の割り当て**：30本を以下の型に配分する（偏りを防ぐ）

   | 型 | 本数 | 内容 |
   |---|---|---|
   | 共感（悩みの代弁） | 6 | 読者の生の声から始める |
   | ノウハウ切り出し（無料で価値提供） | 7 | 記事の要点を1つだけ渡す |
   | 体験・ストーリー | 4 | 筆者の失敗・気づき（要追記箇所は【要追記】表記） |
   | 問いかけ・アンケート | 3 | リプライ・投票を促す |
   | 記事紹介（直接告知） | 5 | 目次・得られること・価格を明示 |
   | 読者の声・Q&A想定 | 2 | よくある疑問に答える |
   | リマインド・締め | 3 | 公開後の再告知 |

3. **執筆**：各ポスト140字以内（全角）。1ポスト1メッセージ。冒頭1行で手を止めさせる
   - 告知リンクを入れるのは「記事紹介」「リマインド」型のみ（`{note_URL}` で置換用に記載）
   - ハッシュタグは0〜2個
4. **投稿スケジュール案**：公開前3日〜公開後11日の14日間に30本を配置し、推奨時間帯を付ける
5. **固定ポスト案**を1本別途作成する（スレッド形式可）
6. 自己チェック表を埋めて統括へ提出する

## 成果物：`deliverables/03_x_posts.md`
```
# X告知ポスト
## 訴求軸リスト
## 投稿一覧
| No | 型 | 投稿日（公開日=D） | 時間帯 | 本文 | 字数 | リンク有無 |
（30行）
## 固定ポスト案
## 自己チェック表
```

## 品質チェック基準
| # | 基準 | 合格ライン |
|---|---|---|
| 1 | 本数 | ちょうど30本＋固定ポスト1本 |
| 2 | 字数 | 全ポストが140字以内（全角換算） |
| 3 | 型の配分 | 上表の配分どおり（±1本まで） |
| 4 | 重複なし | 冒頭1行が同じ・ほぼ同じポストがない |
| 5 | 記事との整合 | 記事に書かれていない内容・効果を約束していない |
| 6 | 誠実さ | 煽り・誇大表現・収益の断定がない。ステマ的表現がない |
| 7 | リンク運用 | リンク付きは「記事紹介」「リマインド」型のみ |
| 8 | 制約遵守 | アカウントのトーン・NG表現に沿っている |
