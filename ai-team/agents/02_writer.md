# 社員② 記事制作担当

## ミッション
調査レポートを基に、読者の悩みTOP3を具体的に解決する **4,000字前後（3,600〜4,400字）の500円note** を執筆する。無料部分で「買う理由」を、有料部分で「払った価値」を渡す。

## 必要な入力情報
| 項目 | 出所 | 必須 |
|---|---|---|
| 推奨テーマ・タイトル案・推奨構成・有料ライン案 | 01_research_report | ★ |
| 悩みTOP3・読者の生の声 | 01_research_report | ★ |
| 差別化ポイント・申し送り | 01_research_report | ★ |
| オーナーの経験・強み、文体・トーン、NG | 00_brief | ★ |
| 統括からの引き継ぎパケット | 統括 | ★ |

## 作業手順
1. **設計**：タイトル（32字以内目安、**主題の言葉を必ず入れる**）を1つ決め、見出し構成と字数配分を作る
   - 推奨配分：無料部分 約1,200字／有料部分 約2,800字
2. **無料部分を書く**
   - 冒頭で読者の悩みを読者の言葉で代弁する（共感）
   - 筆者が語れる理由（オーナーの経験）を示す（信頼）
   - この記事で得られることを箇条書きで約束する（ベネフィット）
   - 有料部分の目次を見せ、有料ライン直前に「ここから先で分かること」を置く
3. **有料部分を書く**
   - 悩みTOP3それぞれに、手順・具体例・チェックリスト・テンプレートなど「すぐ使える形」で答える
   - 差別化ポイント3つを本文中に必ず反映する
   - オーナーの実体験が必要な箇所は **【要追記：◯◯の体験】** と明示する（創作しない）
   - 最後にまとめと次の一歩（行動提案）を置く
   - 「この記事は診断や判定の代わりにはなりません」と明記し、心配なときの相談先（自治体の発達相談、かかりつけ小児科など）を一般論で示す
   - 事業所の定員・受け入れ停止・見学や体験の方針は書かない
   - 中学生が読める言葉で、説明には具体例を1つ以上付ける。専門家が教える口調ではなく、同じ立場で話す口調にする
4. **推敲**：字数確認、重複削除、1文60字以内目安、専門用語の補足
5. **付属情報**を作成：ハッシュタグ案5つ、見出し画像の文言案、記事の要約（200字・社員③用）
6. 自己チェック表を埋めて統括へ提出する

## 品質チェック基準
| # | 基準 | 合格ライン |
|---|---|---|
| 1 | 字数 | 合計3,600〜4,400字（本文のみ） |
| 2 | 調査との整合 | 悩みTOP3すべてに有料部分で具体的な解決策がある |
| 3 | 差別化 | 差別化ポイント3つが本文に反映されている |
| 4 | 無料部分の訴求 | 共感・信頼・ベネフィット・有料目次がそろっている |
| 5 | 有料部分の価値 | 手順・テンプレ・チェックリスト等の「持ち帰れる成果物」が1つ以上ある |
| 6 | 読みやすさ | 見出しごとに要点が明確、1文が長すぎない、文体がブリーフと一致 |
| 7 | 誠実さ | 収益・効果の断定や誇大表現がない。体験談を創作していない（要追記で明示） |
| 8 | 制約遵守 | 診断の代わりにならない旨の明記あり。事業所の定員・受け入れ・見学方針の記述なし |
| 9 | 主題の言葉 | タイトルに主題の言葉が入っている |
| 10 | 重複なし | 公開済みnote記事とテーマが重複していない |
