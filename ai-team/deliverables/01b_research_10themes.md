## テーマ別の整理

### 1. 2〜3歳のことば：単語の数より見てほしいところ

| 項目 | 内容 |
|---|---|
| 想定読者 | 2〜3歳でことばが少なく、単語の数を数えて不安になっている保護者 |
| 悩み | 「何個出ていれば大丈夫？」「家で何をすれば？」「私の話しかけが足りない？」 |
| 競合 | HugKum「語彙数だけではわからない」（言語聴覚士監修、家庭のコツ5つ）[1]。自治体の目安資料[2][3] |
| 競合の不足点 | 指さし・視線・要求の出し方を家で見るためのチェック表がない。相談につなげる目安もない |
| 差別化 | 療育で実際に見ているところを親向けの言葉に変える。発達ゆっくりの双子の親としての体験 |
| 需要の根拠 | 1歳半・3歳健診のたびに新しい読者が生まれる。オーナーのThreadsで「数ではなく」の投稿に反応あり |

### 2. 健診で「様子見」と言われた後の過ごし方

| 項目 | 内容 |
|---|---|
| 想定読者 | 1歳半・3歳健診で「様子を見ましょう」と言われた保護者 |
| 悩み | 「本当に待っていていいの？」「次の健診まで何もしなくていい？」 |
| 競合 | プレジデントオンライン：「様子見でよいか評価を受けて」と専門家が解説[4]。All About：健診で見ている項目[5] |
| 競合の不足点 | 様子見の期間に家で何を記録し、いつ再相談するかの具体的な手順がない |
| 差別化 | 「様子見＝何もしない期間」にしないための記録表と、再相談の目安をセットで渡す |
| 需要の根拠 | 健診は毎年すべての子が受けるので、読者は途切れない |

### 3. 初めての発達相談で困らない「伝えるメモ」の作り方

| 項目 | 内容 |
|---|---|
| 想定読者 | 自治体の発達相談・療育センターの初回面談を控えている保護者 |
| 悩み | 「何を聞かれるの？」「当日、頭が真っ白になって伝えられなかった」 |
| 競合 | 自治体の問診票・質問シート（出生時の様子、発達歴、相談歴など）[6][7]。大津市の案内（相談したいことを整理して予約）[8] |
| 競合の不足点 | 問診票の項目はあっても、親向けの書き方の例がない |
| 差別化 | 相談を受ける側（心理士）が「この書き方だと伝わる」を例つきで示す。既存の固定記事「発達検査の結果表」の前段になり、記事同士をつなげやすい |
| 需要の根拠 | 相談は年中受け付けていて、初回の不安はいつも同じ【推測】 |

### 4. 診断前でも始められる、受給者証の取り方と最初の電話

| 項目 | 内容 |
|---|---|
| 想定読者 | 療育を勧められたが、手続きが分からず止まっている未就学児の保護者 |
| 悩み | 「診断がないと使えない？」「どこに電話して何を言えばいい？」 |
| 競合 | 自治体ごとの手引き（豊島区・入間市・袋井市・市川市など）[11][12][13] |
| 競合の不足点 | 自治体ごとにばらばらで、「最初の電話で何を言うか」の文例がない |
| 差別化 | 流れの全体図と、電話で使える文例・聞くことリスト |
| 注意点 | 公開済みの「放デイ探し」記事と読者が一部重なる。未就学と手続きに絞る。**事業所の受け入れ方針は書かない** |

### 5. 園の先生に「うちの子の発達」を相談する伝え方

| 項目 | 内容 |
|---|---|
| 想定読者 | 保育園・幼稚園に通う子の発達が気になる保護者 |
| 悩み | 「先生にどう切り出せばいい？」「加配ってどう頼むの？」「モンスターペアレントと思われたくない」 |
| 競合 | 研究論文：加配は保護者の申請で動く仕組みが多く、申請がないと制度の外になる[14]。船橋市：同意を得て園とセンターで情報を共有する流れ[15] |
| 競合の不足点 | 親の立場から書いた「伝え方の文例」がほとんど見つからない【推測】 |
| 差別化 | 園と保護者の両方の事情が分かる立場から、連絡帳・面談で使える文例を示す |
| 需要の根拠 | 毎年4月の入園・進級と、秋の面談の時期に検索が増える【推測】 |

### 6. 切り替えが苦手：公園から帰れない子への見通しの伝え方

| 項目 | 内容 |
|---|---|
| 想定読者 | 遊びを終われない、次の行動に移れずに毎回泣いてしまう幼児の保護者 |
| 悩み | 「公園から帰るたびに大泣き」「時間がかかって毎日疲れる」 |
| 競合 | プレジデントオンライン：ペアレント・トレーニングの「予告」「CCQ」[9]。大阪市：見て分かる支援[10] |
| 競合の不足点 | 「公園」「お風呂」など場面ごとの具体例が少ない |
| 差別化 | よくある5場面ごとの予告の言い方と、手作りの見通しカードの作り方 |
| 需要の根拠 | ASD傾向に限らず多くの幼児の親に当てはまり、読者が広い【推測】 |

### 7. かんしゃく・パニックの最中と後の対応

| 項目 | 内容 |
|---|---|
| 想定読者 | 毎日のかんしゃくで疲れきっている保護者 |
| 悩み | 「どう声をかけても止まらない」「外だと周りの目がつらい」 |
| 競合 | 愛知県：行動の背景を氷山モデルで考える[16]。現代ビジネス：ABAの考え方[17]。書籍の紹介記事など、数が多い |
| 競合の不足点 | 数は多いが理論寄りで、「その場の3分」に絞ったものは少ない【推測】 |
| 差別化 | 「最中・直後・落ち着いてから」の3段階に分け、外出先に絞った対応表 |
| 注意点 | 競合が多い。医療が必要なケースもあるので、相談の目安を必ず入れる |

### 8. 食べられるものが少ない子の偏食：家でできる小さな工夫

| 項目 | 内容 |
|---|---|
| 想定読者 | 決まったものしか食べない（白いご飯だけ、同じメーカーだけなど）幼児の保護者 |
| 悩み | 「栄養が心配」「毎食作るのがつらい」「無理に食べさせるべき？」 |
| 競合 | 四條畷学園大学の研究：「終わりと次を明確に」「決まったメーカー」「一口サイズ」「混ぜない」[19]。英語の論文・海外の情報[20] |
| 競合の不足点 | 研究で効果が出ている工夫が、日本語の親向けの記事にまとまっていない【推測】 |
| 差別化 | 研究で示された工夫を「今日からできる7つ」にまとめる。感覚の特性の説明つき |
| 注意点 | 栄養や体重の心配は小児科の領域。医療につなぐ目安を入れる |

### 9. 祖父母・夫に子どもの特性を分かってもらう伝え方

| 項目 | 内容 |
|---|---|
| 想定読者 | 「甘やかしすぎ」「そのうち話す」と言われ、家族の中で孤立している保護者 |
| 悩み | 「祖父母が特性を理解してくれない」「夫と温度差がある」 |
| 競合 | パステル総研の調査：祖父母との困りごとの1位が「特性を理解しない」49.4%[21]（有効回答107人のネット調査）。九州大学の論文：祖父母は知識が少なく、親の育て方を責めやすい[22] |
| 競合の不足点 | 「どう説明すればいいか」の文例がほとんどない【推測】 |
| 差別化 | 専門職として家族に説明してきた経験から、相手別（祖父母・夫）の伝え方と、そのまま使える説明文 |
| 需要の根拠 | お盆・年末年始の帰省前に悩みが増える【推測】 |

### 10. きょうだい児：発達特性のある子の兄弟が寂しくないように

| 項目 | 内容 |
|---|---|
| 想定読者 | 発達特性のある子にかかりきりで、ほかのきょうだいへの関わりが足りないと感じている保護者 |
| 悩み | 「下の子（上の子）に我慢させている」「いい子すぎて心配」 |
| 競合 | HugKum：きょうだい児の課題[23]。All About・ELEMINISTなどの解説[24][25] |
| 競合の不足点 | 「きょうだい児とは」の解説が中心で、忙しい親が毎日できる工夫が少ない |
| 差別化 | ASDの兄と発達ゆっくりの双子を育てる当事者の視点。1日5分でできる関わり |
| 注意点 | 家族の話が中心になるため、書いてよい範囲をオーナーに確認する |

## あなたの経験を活かせるテーマ3つ（推奨）

| 順位 | テーマ | 活かせる経験 | 選んだ理由 |
|---|---|---|---|
| 1 | **#1 2〜3歳のことば：単語の数より見てほしいところ** | 療育の現場で見ているところ（専門職）／発達ゆっくりの双子（親） | Threadsで実際に反応が出た切り口。専門職と親の両方の視点を出せる |
| 2 | **#3 初めての発達相談で困らない「伝えるメモ」の作り方** | 公認心理師・臨床心理士として相談を受ける側にいた経験 | 「受ける側」が書く記事はほとんど見つからない。固定記事「発達検査の結果表」へ自然につながる（相談 → 検査 → 結果の読み方） |
| 3 | **#9 祖父母・夫に子どもの特性を分かってもらう伝え方** | 専門職として家族に説明してきた経験／ASDの子の親としての経験 | 困りごとの1位というデータがある[21]のに、文例を出している記事がほとんどない。「そのまま使える説明文」で500円の価値を出しやすい |

次点は **#10 きょうだい児**。3人きょうだいを育てる当事者としての強みは最も大きいですが、家族のことを書ける範囲をオーナーに確認する必要があるため、次点にしました。
