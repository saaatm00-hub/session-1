# 購入者の悩み 深刻度ランキング（69個）

evergreen_blue_ocean.md のテーマを買う人が抱えている悩みを、深刻な順に並べました。各悩みには、その悩みに答えるテーマを競合が少ない順に最大4本つけています。

> 注意: アンケートや購入データにもとづく数値ではありません。下の3つの基準で付けた推定値です。

## 深刻度の付け方（各1〜5点、合計3〜15点）

- **緊急性**：今すぐ解決しないと困るか（期限が迫っている、毎日つらい）
- **損失の大きさ**：放っておくと失うものの大きさ（お金、健康、家族、キャリア）
- **自力解決の難しさ**：検索や無料情報だけでは解決しにくいか（個別の事情が絡む、人に相談しにくい）

深刻度が高い悩みほど「500円で答えが手に入るなら買う」という判断が早くなります。
