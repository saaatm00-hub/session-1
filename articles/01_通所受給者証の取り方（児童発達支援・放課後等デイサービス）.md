# 「受給者証を取ってきてください」と言われたあなたへ。窓口で迷わないための申請準備ノート

「では、受給者証が出たらご連絡くださいね」

見学した事業所でそう言われて、笑顔でうなずいた。帰りの車の中で、ふと気づく。受給者証って、どこでもらうものなんだろう。

検索すると、市役所の福祉課、相談支援事業所、セルフプラン、支給量……。知らない言葉が次々に出てきます。どのページも説明は正しい。でも「で、明日わたしは何をすればいいの？」には答えてくれない。

しかも、事業所の空き枠はいつまで残っているかわかりません。「今なら週2で入れます」と言われたあの枠が、手続きにもたついている間に埋まってしまうかもしれない。焦りますよね。

[ここに体験]

このnoteでは、受給者証の申請を「窓口に行く前」「窓口と聞き取り」「受け取りまで」の3つに分けて、実際に何をするかを1動作ずつ書いています。聞き取りで使える回答準備シートと、利用日数の理由を伝える文例もつけました。

---

## このnoteが向いていない人

先にお伝えしておきます。次のような方には、このnoteは合わないかもしれません。

- **すでに受給者証を持っていて、更新の手続きだけ知りたい方。** 更新は自治体ごとの差が大きく、このnoteでは扱っていません。
- **手帳や手当の申請方法を知りたい方。** 受給者証は療育手帳とは別の制度です。このnoteは受給者証に絞っています。
- **お住まいの自治体の具体的な締め切りや必要書類を知りたい方。** 自治体によって違うため、ここには書けません。そのかわり「窓口で何を確認すればいいか」のリストを用意しています。
- **事業所選びで迷っている方。** 事業所を比べるときの視点は、また別のテーマになります。このnoteは「通いたい事業所がだいたい決まった」段階の方向けです。

## 全体の流れを3ステップで

細かい手順に入る前に、全体像です。

**ステップ1：窓口に行く前に、3つのことを決めておく**
通いたい事業所、週に何日通いたいか、計画を誰に作ってもらうか。この3つが決まっていないと、窓口で「では、それが決まったらまた来てください」と言われることがあります。

**ステップ2：窓口で申請し、聞き取り調査を受ける**
聞き取り調査とは、自治体の担当者が子どもの様子や家庭の状況を質問する面談のことです。ここで話した内容が、利用できる日数（支給量）の判断材料になります。

**ステップ3：利用計画を出して、受給者証を受け取る**
障害児支援利用計画（どの事業所に、週何日、何のために通うかをまとめた書類）を提出します。それが通ると受給者証が届き、事業所と契約できるようになります。

申請してから届くまでの期間は、自治体や時期によってかなり違います。数週間で届くところもあれば、年度初めの混む時期には1〜2か月かかることもあるようです。だからこそ、ステップ1の準備で行ったり来たりを減らしておくと楽になります。

## 手順を1つずつ

ここからは1手順1動作で書いていきます。番号の順に進めてください。

### ステップ1：窓口に行く前に

**1. 通いたい事業所の名前と連絡先をメモする**
候補が2つあれば、2つとも書いておきます。窓口で「併用ですか？」と聞かれることがあるからです。

**2. 事業所に「受給者証の申請を始めます」と電話で伝える**
このとき「計画を作ってくれる相談支援事業所を紹介してもらえますか」と一言添えます。事業所は地域の相談支援事業所とつながっていることが多く、ここで紹介してもらえるとかなり早く進みます。

**3. 週に何日通いたいかを決める**
「とりあえず週1」でもかまいません。ただ、あとで増やすには変更の手続きが必要です。迷ったら、事業所から提案された日数をそのまま書くのがいちばん通りやすい、というのが私の実感です。

**4. 計画の作り方を決める**
選択肢は2つあります。

- 相談支援専門員（計画作りを専門にする支援者）に作ってもらう
- 保護者が自分で作る（セルフプランと呼ばれます）

相談支援専門員は地域によって足りておらず、「半年待ち」と言われることもあります。待てない場合はセルフプランを選ぶ人が多いです。セルフプランの書き方は、このあとのテンプレートに入れています。

**5. 自治体のサイトで担当窓口の名前を調べる**
「障害福祉課」「子ども発達支援課」など、名前は自治体によってばらばらです。「受給者証 ○○市」で検索すると出てくることが多いです。

**6. 窓口に電話して、予約が必要かどうかを聞く**
予約制の自治体では、いきなり行くと出直しになります。電話では、このあとの「窓口で確認すること」リストもあわせて聞いておくと安心です。

### ステップ2：窓口と聞き取り

**7. 持ち物をそろえる**
一般的には、子どもと保護者のマイナンバーがわかるもの、保護者の本人確認書類、印鑑、診断書や医師の意見書（ある場合）、療育手帳（ある場合）などです。ただし自治体によって違うので、手順6の電話で確認したものを優先してください。

**8. 「回答準備シート」を埋めておく**
聞き取りでは、思っている以上に細かく聞かれます。食事、着替え、トイレ、ことば、集団での様子、夜眠れているか……。その場で思い出そうとすると、ふだんの大変さが出てきません。シートはこのあとのテンプレートにあります。

**9. 窓口で申請書を書く**
書き方がわからない欄は、空けたまま担当者に聞いて大丈夫です。

**10. 聞き取り調査を受ける**
その日のうちに窓口で行う自治体と、後日、家庭訪問で行う自治体があります。

**11. 利用日数の理由を伝える**
「週2日を希望します。理由は〜」と、理由まではっきり言葉にします。ここがいちばん大事なところです。文例はテンプレートに入れました。

### ステップ3：計画の提出から受け取りまで

**12. 計画案を提出する**
相談支援専門員に頼んだ場合は、専門員が出してくれます。セルフプランの場合は自分で提出します。

**13. 届くまでの目安の日を聞いておく**
「いつごろ届きますか」と聞いて、メモしておきます。

**14. 届いたら、記載内容を確認する**
受給者証に書かれた「支給量（ひと月に使える日数）」と「有効期間」を見ます。希望と違っていたら、すぐ窓口に連絡します。

**15. 事業所に連絡して、契約日を決める**
受給者証のコピーを事業所に渡すことが多いので、コピーを1枚とっておくとスムーズです。

## つまずきやすい箇所と、その場での対処

### 聞き取りで「できます」と言ってしまう

いちばん多いのがこれです。担当者に「着替えはできますか？」と聞かれて、つい「できます」と答えてしまう。実際は、声かけを5回して、最後は手伝って、やっと着られている。それでも口から出るのは「できます」なんですよね。

[ここに体験]

**その場での対処：** 言ってしまったと気づいたら、「すみません、正確に言うと、声かけを何度かして、半分くらいは手伝っています」と言い直してください。言い直していいんです。担当者は「どのくらいの手助けで、できているか」を知りたいので、むしろ助かるはずです。

### 「診断がないと無理ですよ」と言われた

自治体によっては、診断書がなくても医師の意見書や、保健センターの発達相談の記録などで申請できる場合があります。

**その場での対処：** 「診断名がなくても、医師の意見書や相談記録で申請できる方法はありますか」と聞き返してみます。それでも難しいと言われたら、「では、どの書類があれば申請できますか」と、次に何をそろえればいいかを聞いてメモします。

### 希望より少ない日数で決まった

**その場での対処：** 受給者証が届いたあとでも、変更の申請ができる自治体が多いです。「園での様子が変わった」「事業所から増やすことを勧められた」など、新しい理由をそろえてから相談すると話が進みやすくなります。

### セルフプランの「目標」が書けない

「目標」と書かれた欄で手が止まる人はとても多いです。立派なことを書かなきゃ、と思ってしまう。

**その場での対処：** 今いちばん困っていることを、そのまま裏返すだけで目標になります。「朝の着替えで毎日泣いて遅刻する」なら、「朝の着替えの手順がわかり、声かけ2回以内で着替えられる」。これで十分通用します。

## そのまま使えるテンプレートと文例

### 窓口に電話で確認すること（チェックリスト）

- □ 申請は予約制ですか
- □ 必要な持ち物は何ですか
- □ 診断書がない場合、代わりになる書類はありますか
- □ 聞き取りはその日に行いますか、後日ですか
- □ セルフプランの様式はどこでもらえますか
- □ 申請から届くまでの目安はどれくらいですか
- □ 相談支援事業所の一覧はもらえますか

### 聞き取り回答準備シート

各項目について「一人でできる／声かけでできる／手伝いが必要／できない」のどれに当てはまるかと、具体的な場面を1行ずつ書いておきます。

| 項目 | どの程度か | 具体的な場面（1行） |
|---|---|---|
| 食事 | | 例：苦手な食感があると口から出し、食べられるものが10品くらい |
| 着替え | | 例：前後がわからず、毎朝声かけ3〜4回、最後は手伝う |
| トイレ | | 例：日中はできるが、遊びに夢中だと間に合わない |
| ことば・やりとり | | 例：要求は言えるが、質問への返事がずれることが多い |
| 集団での様子 | | 例：園の朝の会で座っていられず、部屋を出てしまう |
| 切り替え | | 例：公園から帰るときに20分以上泣く |
| 睡眠 | | 例：寝つくまで1時間以上かかり、夜中に2回起きる |
| 危険の理解 | | 例：道路に飛び出しそうになるので手を離せない |
| 家族の状況 | | 例：双子の弟もいて、送迎を一人で担っている |

**書くときのコツ：** 調子がいい日ではなく、ふつうの日（またはちょっと大変な日）を基準に書きます。

### 利用日数の理由を伝える文例

> 週2日の利用を希望しています。
> 理由は、園で集団活動に参加できない時間が長く、先生からも個別の支援の必要性を伝えられているためです。
> 事業所からは、ことばのやりとりと切り替えの練習を週2回続けることを提案されています。
> 家庭では下に小さいきょうだいがいて、一対一で関わる時間を十分に取れない状況です。

ポイントは3つです。①園や学校など、家庭の外で困っていること、②事業所が何をしてくれる予定か、③家庭だけでは支えきれない事情。この3つがそろうと、担当者は判断の根拠を記録しやすくなります。

### セルフプランの記入例（目標の欄）

| 困っていること | 目標 | 事業所で取り組むこと |
|---|---|---|
| 朝の着替えで毎日泣く | 手順カードを見て、声かけ2回以内で着替える | 手順カードを使った着替えの練習 |
| 友だちのおもちゃを取ってしまう | 「かして」と言葉で伝えられる | 小集団でのやりとりの練習 |
| 帰る時間に切り替えられない | タイマーを見て、次の行動に移れる | 見通しを伝える支援 |

## まとめ

受給者証の手続きは、制度の名前が難しいせいで大きな山に見えます。でも、やることを一つずつほどいていくと、「電話する」「書く」「話す」「受け取る」の積み重ねです。

いちばん差がつくのは、聞き取りの場面です。ふだんの大変さを、遠慮せずに具体的な場面で伝える。「できます」と言ってしまったら、その場で言い直す。それだけで、子どもに合った日数につながる可能性が上がります。

[ここに体験]

受給者証が届いたら、いよいよ事業所との契約です。そこから先は、個別支援計画（事業所が作る、お子さんの支援の計画書）の読み方が気になってくると思います。それはまた別のnoteでまとめる予定です。

まずは今日、窓口への電話を一本。それだけでも、ちゃんと前に進んでいます。
