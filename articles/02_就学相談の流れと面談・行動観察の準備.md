# 就学相談の面談で、言いたいことを言い残さないための準備ノート

就学相談の案内の紙、冷蔵庫に貼ったままになっていませんか。

申し込み期限は来月。でも、申し込んだら支援級に決められてしまうのでは？　面談で何を聞かれるの？　行動観察（子どもが遊んだり課題に取り組んだりする様子を、担当者が見る時間）で、うちの子がいつもの調子を出せなかったらどうしよう。

考えはじめると止まらなくて、紙を見るたびに胃のあたりが重くなる。

園の先生には「受けておいたほうが安心ですよ」と言われた。ママ友には聞きにくい。検索すると、体験談はたくさん出てくるけれど、自治体によって流れが違いすぎて、自分の場合にどう当てはまるのかがわからない。

[ここに体験]

このnoteでは、就学相談の「面談」と「行動観察」の当日に向けて、保護者がやっておくことを順番に並べました。面談で話す内容を整理するシートと、そのまま読み上げられる文例もつけています。

---

## このnoteが向いていない人

- **支援級・通級・通常級のどれを選ぶか、比べ方を知りたい方。** このnoteは「就学相談の場で、どう伝えるか」に絞っています。学びの場の比べ方は別のテーマです。
- **入学前に学校へ渡す引き継ぎ資料の作り方を知りたい方。** それも別のnoteで扱う予定です。
- **すでに判定が出て、その結果に不服がある方。** 少しだけ触れますが、中心ではありません。
- **お住まいの自治体の日程や様式を知りたい方。** ここでは一般的な流れを扱います。日程は自治体の案内を確認してください。

---

## 全体の流れを3ステップで

**ステップ1：申し込み前に「家庭の意向」を言葉にしておく**
就学相談は、保護者の意向を聞く場でもあります。現在の制度では、本人と保護者の意向を可能なかぎり尊重することになっています。だからこそ、意向が言葉になっていないと、話が専門家側のペースで進みやすくなります。

**ステップ2：面談と行動観察の当日に備える**
面談では、生まれてから今までのこと、園での様子、家庭での困りごとを聞かれます。行動観察では、担当者が子どもの様子を見ます。どちらも「ふだんの姿を伝える」ことが目的です。

**ステップ3：判定のあと、話し合いの場を使う**
就学支援委員会（教育や医療の専門家が集まって、学びの場について意見をまとめる会議）の結果が伝えられます。ここが終わりではなく、そこから保護者と教育委員会の話し合いが続く、と考えておくと気持ちが楽になります。

## 手順を1つずつ

### ステップ1：申し込み前に

**1. 案内の紙から「申し込み期限」と「面談の時期」を書き出す**
カレンダーに2つの日付を書き込みます。それだけで、頭の中のもやもやが少し減ります。

**2. 家庭の意向を、今の時点で1行書く**
「通常級で、困ったときに通級を使いたい」「まだわからない。見学してから決めたい」。わからない、でも立派な意向です。

**3. 園の先生に、就学相談を申し込むことを伝える**
自治体によっては、園から子どもの様子を書いた書類が出されます。伝えておかないと、園側の準備が間に合わないことがあります。

**4. 園の先生に「園での様子で、気になっていることを3つ教えてください」と聞く**
家と園で見せる姿は違うことが多いです。家ではしっかり話せるのに、園では固まっている。逆もあります。面談で「園ではどうですか」と聞かれて答えられないと、焦ります。

[ここに体験]

**5. 申込書を出す**
多くの場合、教育委員会の担当課に出します。電話で申し込む自治体もあります。

### ステップ2：面談と行動観察の当日に向けて

**6. 面談準備シートを埋める**
このあとのテンプレートを使います。全部埋めなくてかまいません。空欄があるのは自然なことです。

**7. 母子手帳と、これまでの相談・検査の記録を1つのファイルにまとめる**
健診の結果、発達検査の結果、療育先の個別支援計画など。面談中に「いつごろ言葉が出ましたか」と聞かれたとき、ページをめくれば答えられるようにしておきます。

**8. 面談で「いちばん伝えたいこと」を3つに絞って、紙に書く**
話しているうちに、聞かれたことに答えるだけで時間が終わってしまう。これがいちばんよくある後悔です。3つだけ書いた紙を、手元に置いておきます。

**9. 子どもに「今日は○○へ行って、先生と遊ぶよ」と前日に伝える**
見通しがないと固まってしまう子は多いです。「テストする」ではなく「遊ぶ」「お話しする」と伝えるほうが、構えずに済むことが多いです。

**10. 当日の朝、体調と睡眠をメモする**
「昨夜は寝つくのに時間がかかった」「朝ごはんを食べられなかった」。行動観察のあとに担当者に伝えられるようにしておきます。

**11. 行動観察のあいだ、子どもへの声かけは控えめにする**
担当者は、ふだんの様子を見たいと考えています。手伝いたくなる気持ちをぐっとこらえる時間です。正直、これがいちばんつらかったという声をよく聞きます。

**12. 行動観察のあと、「ふだんとの違い」を担当者に伝える**
「家では、もっと話します」「今日はいつもより落ち着いていました」。どちらの方向でも伝えます。

### ステップ3：判定のあと

**13. 判定の結果と理由を、メモをとりながら聞く**
結果だけでなく「なぜそう考えたか」を聞いておくと、次に話すときの材料になります。

**14. 家庭の意向と違っていたら、その場で「持ち帰って考えます」と言う**
その場で返事をする必要はありません。

**15. 学校見学や体験の機会があるかを聞く**
実際に見てから決めたいことを伝えます。見学の機会は、自治体によっては保護者から頼まないと用意されないこともあります。

## つまずきやすい箇所と、その場での対処

### 行動観察で、子どもがいつもと違う姿を見せた

人見知りして、何もしゃべらない。逆に、初めての部屋にテンションが上がって走り回る。よくあることです。

[ここに体験]

**その場での対処：** 終わったあとに「今日の様子は、家ではあまり見ない姿です。ふだんはこうです」と具体的に伝えます。スマホに家での動画があれば、見せてもいいか聞いてみるのも一つの方法です。

### 面談で、聞かれたことに答えるだけで終わりそうになった

**その場での対処：** 時間の最後に「最後に、伝えておきたいことが3つあります」と切り出します。準備した紙を読み上げてかまいません。読み上げることは、まったく失礼ではありません。

### 「支援級のほうがいいと思いますよ」と、その場で強く勧められた

**その場での対処：** 「そう考える理由を教えていただけますか」と聞きます。理由を聞いてメモをとる。それだけで、気持ちの上で一歩引いて考えられます。返事は持ち帰って大丈夫です。

### 夫婦で意見が分かれている

**その場での対処：** 面談の前に、「一致していること」と「迷っていること」を分けて紙に書いておきます。面談では「ここは2人とも同じ考えです。ここはまだ話し合い中です」と伝えれば、それで十分です。

### 面談の日程が、仕事や下の子の予定とぶつかる

就学相談の日程は、平日の日中に指定されることが多いです。仕事を休めない。下の子を預ける先がない。双子だと、相談を受ける子ともう一人をどうするか、という問題も出てきます。

**その場での対処：** 日程の連絡が来た時点で、「別の日に変更できますか」「きょうだいを連れて行ってもいいですか」と遠慮せずに聞きます。きょうだいを連れて行く場合は、面談中に別室で見てもらえることもあります。聞いてみないとわからないので、まずは一度、電話で確認してみてください。

### 子どもが「行きたくない」と言う

前日に予定を伝えたら、「行かない」と言い出した。当日の朝、玄関から動かない。

**その場での対処：** 無理に連れて行かず、担当者に電話で状況を伝えます。「行きたくないと言って動けない」という姿も、子どもを知るための大切な情報です。日を改めることになっても、それは失敗ではありません。次の日程の前に、場所の写真を見せたり、建物の前まで散歩で行ってみたりすると、見通しが持ちやすくなることがあります。

### 判定の結果に納得できない

**その場での対処：** 結果の理由をもう一度聞き、「もう一度話し合う機会はありますか」と確認します。多くの自治体では、就学先の最終的な決定まで話し合いを重ねる流れになっています。

## そのまま使えるテンプレートと文例

### 面談準備シート

| 項目 | 書くこと | メモ |
|---|---|---|
| 家庭の意向 | 今の時点の希望（迷っていてもOK） | |
| 生まれてからの様子 | 言葉が出た時期、歩いた時期、健診で言われたこと | |
| 診断・検査 | 診断名、検査を受けた時期と結果のポイント | |
| 園での様子 | 先生から聞いた気になること3つ | |
| 家庭での様子 | 困っていること、うまくいっている工夫 | |
| 得意なこと・好きなこと | 学校生活で生かせそうなこと | |
| 療育・支援 | 通っている場所、頻度、取り組んでいること | |
| 心配なこと | 入学後に起きそうだと思うこと | |
| いちばん伝えたいこと | 3つに絞って書く | |

### 面談で読み上げられる文例

**意向がはっきりしている場合**

> 私たちは、通常の学級で学びながら、必要に応じて通級を利用することを希望しています。
> 理由は、本人がクラスの友だちと一緒に過ごすことを楽しみにしていること、また、音への敏感さなど配慮があれば参加できる場面が多いと考えているためです。
> 一方で、集団での一斉指示が通りにくいことは心配しています。その点について、どんな支援が受けられるか教えていただきたいです。

**まだ迷っている場合**

> 正直なところ、まだどの学びの場がいいのか決めきれていません。
> 学校を見学してから考えたいと思っています。
> 見学できる機会があれば教えてください。

**行動観察のあとに伝える場合**

> 今日は初めての場所で緊張していたようで、ふだんより言葉が少なかったです。
> 家では二語文、三語文で話しています。
> 好きな電車の話になると、もっとたくさん話します。

## まとめ

就学相談は、学びの場を「決められる」場所ではなく、「一緒に考える」場所です。そう頭でわかっていても、当日は緊張します。言いたいことがあったのに、帰りの車で思い出す。そんな後悔を減らすために、紙に書いて持っていく。それがこのnoteでいちばん伝えたかったことです。

[ここに体験]

就学相談が終わったら、次は「支援級・通級・通常級をどう選ぶか」、そして「学校に何をどう引き継ぐか」が気になってくると思います。そのテーマもそれぞれまとめていく予定です。

まずは、冷蔵庫の案内の紙から、2つの日付を書き出すところから始めてみてください。

## 次に読むなら

面談の準備で検査結果のコピーを出してきたものの、数値の意味をうまく説明できなかった方へ。

結果用紙を「範囲」と「差」で読み直し、生活の場面とつなげる手順をまとめています。面談前の整理に使えるかもしれません。

→ 『発達検査の結果用紙を、自分の言葉で読み直すためのノート（WISC-V・新版K式）』

検査をまだ受けていない方や、結果の説明に納得できている方は、読まなくても困りません。
